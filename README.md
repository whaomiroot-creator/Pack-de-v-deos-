# 🎬 Arsenal 20K Vídeos — Landing Page de Alta Conversão

Landing page oficial para divulgação e venda do **Arsenal de Vídeos**, um acervo com mais de 20.000 conteúdos prontos e otimizados para redes sociais (TikTok, Reels, Shorts e canais de nicho).

---

## 🚀 Sobre o Projeto

Esta página foi desenvolvida com foco em conversão direta, apresentando uma interface moderna em *dark theme* com efeitos em ciano/azul elétrico e tipografia marcante.

### 📦 Fluxo de Entrega
1. **Compra Segura:** O cliente conclui o pagamento através da plataforma oficial Cakto.
2. **Acesso à Comunidade VIP:** Entrada imediata no grupo exclusivo do Telegram.
3. **Download e Consulta:** Acesso vitalício às pastas categorizadas no Google Drive.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e acessível.
- **CSS3 Puro:** Estilização responsiva, layout em CSS Grid/Flexbox, variáveis nativas e animações de chamada para ação (CTA).
- **Google Fonts:** Tipografias *Montserrat* e *Inter*.
